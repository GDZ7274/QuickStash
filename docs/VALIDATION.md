## 2026-08-31 重复剪贴板与恢复改动

- 文字和 HTTP(S) 链接按 type、managed origin 与精确内容识别重复；A-B-A 会保留 A 的 ID 和固定状态，并按最新时间回到列表最前。
- 图片指纹基于应用方向后的固定 sRGB RGBA8 紧密像素缓冲区及宽高；同像素 PNG/TIFF 相等，同尺寸不同像素不相等。
- 重复图片保留 canonical 路径并异步删除新产生的冗余 PNG；复用前会在 file-I/O queue 重新解码并核对实际指纹，截断、替换或符号链接路径不会吞掉新图片，新 PNG 会接管旧记录 ID。
- 三次同指纹图片请求在首个异步置顶回调阻塞时正确合并，只使用最后一次观察时间，不触发图片保存或新增记录；generation、取消和终止都会清理 reservation。
- QuickStash 自身 Copy 只有在系统剪贴板写入成功后才置顶；较早的异步图片读取不能覆盖或置顶晚于它发生的文字/图片复制。
- 带 `org.nspasteboard.AutoGeneratedType` 标记的合法图片不再被整条忽略；concealed 和 transient 类型仍保持过滤。
- bootstrap 合并为 incoming ID 建立 canonical alias，使并发删除、固定、复制确认和迟到图片复制继续命中最终记录。
- 冗余图片 discard 会先写 deletion intent；新版 manifest 同时记录源是否存在及其设备号、inode，恢复前重新核对文件身份，同一路径后来出现的新文件不会被旧 intent 误删。损坏 canonical backing 的替换按持久化 intent、metadata 切换与 flush、旧 backing 隔离、manifest 确认的顺序执行。
- 恢复会迁移旧版同像素记录，保留 canonical ID、合并固定状态并采用最新时间；损坏 canonical 可以接管有效同指纹 orphan 的 backing。
- App 退出由 8 秒总预算协调，完成或超时均只回复 macOS 一次。`MainActor` 不同步等待文件 I/O；`ClipboardMonitor` 的单次有界 group wait 位于全局 utility queue。
- 针对上述恢复崩溃窗口、bootstrap alias、路径复用身份校验和退出门禁的确定性测试已纳入测试源；代码停止变更后的最终复验结果见下方。

## 2026-08-27 剪贴板图片可靠性复验

- PNG、TIFF、JPEG、HEIC 和 WebP 单一/后备表示均可读取，并统一生成真实 PNG 历史文件。
- 首选 PNG 暂不可用、数据不完整或输出超限时继续尝试后备图片表示；图片最终不可用时保留同一事件的文字/链接后备。
- TIFF/JPEG 转换保持物理像素尺寸，EXIF 方向转正，TIFF Alpha 保留；旧 TIFF 历史复制时输出 PNG 且原文件不被改写。
- 图片源、单边尺寸、总像素、位深/通道估算解码内存、实际 raster 和 PNG 输出均有上限；PNG 原样保留前校验 chunk、CRC 并立即解码像素。
- 不可取消的同步 provider 最多并行两条；软超时、迟到同计数提交、新旧计数隔离、跨停用 generation、有界退出和保存取消均有确定性回归测试。
- 纯文字和 URL 一次稳定读取即提交；Hosted 实时同步用例连续 10 次通过，明确声明的待就绪图片仍保留后备文字和有限重试。

### 文件与拖放

- 普通窗口拖动不会触发 `.fileURL` 收录界面。
- Finder 文件拖放只在原生 `NSDraggingInfo` 确认后显示和解析。
- 全局指针事件合并、松手清理、看门狗和截图暂停互斥。
- 文件预检、复制、取消、进度、配额、磁盘空间和 recovery manifest。
- import partial、committed orphan 和 deletion manifest 恢复。
- `FailSelectedQuarantine` 按明确标准化源路径注入失败。

### 剪贴板

- 普通文字、显式 URL、纯文本 HTTP(S) 链接，以及 PNG、TIFF、JPEG、HEIC 和 WebP 图片。

- 图片统一 PNG 落盘、格式后备、旧 TIFF 内存转 PNG、迟到 provider 和最多两条读取 lane。
- 内部复制只抑制精确的自身 `changeCount`。
- 外部图片保存不会被后续文字或链接复制取消。
- QuickStash 截图 PNG 在系统写入成功后准确提交一次历史。
- 正常退出在 8 秒全局预算内尽力完成 provisional 文字、URL、进行中图片和 metadata 刷盘；完成或超时只回复一次，未完成的可恢复删除/替换由下次启动继续。
- 重启后内容恢复且不重复。
- bootstrap incoming ID alias 下的删除、固定、复制确认和迟到图片复制。
- deletion/replacement intent 的各崩溃窗口、失败重试与 manifest 确认。
- 旧版同像素记录迁移，以及损坏 canonical 接管有效同指纹 orphan。

## 主线程与死锁审计

`MainActor` 生产路径不使用 `DispatchQueue.main.sync`、同步文件 I/O 或 semaphore/group wait。`ClipboardMonitor.drainPayloadReads` 在全局 utility queue 上执行一次带明确 timeout 的 `DispatchGroup.wait(timeout:)`，再通过 continuation 返回，不会让主线程等待。

生产 Swift 源码不使用 `NSFileCoordinator` 或 `CGWindowListCreateImage`。文件、metadata、渲染、编码和保存工作由专用串行 queue 或 actor 执行；输出状态锁只保护内存 token，不跨越 `remove` 或 `rename` 文件 I/O。
